Why the first Namespace run was slow

GitHub left LC_ALL unset. Namespace set it to C.UTF-8. That changed ccache’s keys: only 3 of 59 compiled objects were reused.

Unsetting it restored all 59 cache hits. The job finished in 80s, versus 126s on GitHub.

env -u LC_ALL python3 scripts/measure_pandas.py
Method and evidence

pandas 717bcd3, Python 3.12, locked Pixi environment, editable Meson build. Two compiler processes and two test workers. Each job used a fresh runner and the same GitHub cache archive.

One trial per configuration. Timings include setup and do not isolate hardware performance. This compares runners using an archive cache; it does not measure Namespace Cache Volumes.

Ccache debug inputs matched after removing LC_ALL. Compiler and checked header manifests also matched. Ccache hashes locale variables.
