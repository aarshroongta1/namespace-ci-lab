Method and limitations

Pinned pandas revision 717bcd3, its locked Pixi Python 3.12 environment, an editable Meson source build, two compiler workers, and two pytest workers. The tests were test_reductions.py and test_groupby.py.

Each job used a fresh runner, checkout, environment, and build directory. Only Pixi packages and ccache outputs persisted. The Python edit renamed a local helper in GroupBy.prod; it did not change native code.

One run per condition, on different underlying hardware. Whole-job times include checkout, apt setup, cache handling, and uploads. For example, installing ccache took 24s on the populated-cache GitHub run and 4s on Namespace; the full difference is not attributable to Cache Volumes. Timelines combine measured command durations and GitHub step timestamps.
